# Project skills

For website or interface design, redesign, implementation, or review, read the
anti-slop core at `.agents/skills/antislop/SKILL.md` before starting UI work.
Resolve its usage mode according to that skill, then load the relevant supplements:

- `.agents/skills/antislop-ui/SKILL.md` for visual design and components.
- `.agents/skills/antislop-copywriting/SKILL.md` for product text and labels.
- `.agents/skills/antislop-human/SKILL.md` for accessibility and interactions.
- `.agents/skills/antislop-layoutmobile/SKILL.md` for responsive layouts.
- `.agents/skills/antislop-code/SKILL.md` when creating or cleaning code comments.

The core is installed as `SKILL.md`; supplement references to `antislop.md` refer
to `.agents/skills/antislop/SKILL.md` in this project.

Use a project `DESIGN.md` to record the visual direction when implementing a
redesign, following the core skill's requirements. Run the applicable delivery
checks before reporting UI work complete.

Installation details and upstream attribution: `docs/ANTI_SLOP.md`.
